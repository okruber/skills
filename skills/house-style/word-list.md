# Word list

Curated from the [Google word list](https://developers.google.com/style/word-list).

## Precision

| Not this | This | Why |
|---|---|---|
| allows you to, lets you | you can | Name the reader as the actor. |
| enable (a person) | let, allow | Reserve *enable* for features and flags. |
| via | with, by using, through | *Via* is vague. |
| e.g. | for example | Latin abbreviations trip up translation. |
| i.e. | that is | Same. |
| etc. | name the rest, or "and so on" | *Etc.* usually hides that you stopped thinking. |
| execute | run | Except where a spec says execute. |
| terminate, kill | stop, end, exit | |
| invalid, illegal | not valid, not allowed | |
| desire, wish | want, need | |
| utilize, leverage | use | |
| in order to | to | |
| prior to | before | |
| subsequent to | after | |
| a number of | many, several, or the number | |
| currently, at this time | delete it | Present tense already says now. |
| going forward | delete it | |

## Do not minimise the work

Never write these about a task: **simply**, **easy**, **just**, **quickly**,
**obviously**, **of course**, **it's that simple**. A reader who is stuck reads
them as an accusation. Delete them and state the number of steps instead.

## Inclusive language

| Not this | This |
|---|---|
| whitelist / blacklist | allowlist / denylist |
| master / slave | primary / replica, main / secondary |
| master (branch) | main |
| sanity check | validation, quick check, confidence check |
| dummy value | placeholder, sample value |
| native (speaker, app) | built-in, platform-specific, or say what you mean |
| grandfathered | legacy, exempt |
| man hours | person hours, engineer hours |
| crazy, insane, lame, blind to | surprising, unexpected, unaware of |
| guys | everyone, folks, all |
| he / she as generic | they |
| cripple | disable, limit |
| tribal knowledge | undocumented knowledge |

Avoid ableist metaphor generally: *blind spot*, *tone deaf*, *paralysed*.

## Timeless writing

Do not pre-announce unreleased work. Do not write *new*, *currently*, *recently*,
*soon*, or *the latest*: they rot. Name the version instead.

Do not write *above* or *below* to refer to page position, since layout varies.
Use *preceding*, *following*, or link to the section by name.

## Numbers and units

Spell out zero through nine in prose. Use numerals for 10 and up. Always use
numerals with units and in tables: `5 GB`, `3 seconds`.

Put a space between the number and the unit, except for degrees and percent:
`45°`, `50%`.

Use unambiguous dates. Write `January 5, 2026` or `2026-01-05`, never `1/5/26`.

Use a serial comma: `flour, eggs, and sugar`.
